# 📊 Power BI Project: [Finanzas Personales]

This project presents an interactive dashboard built in Power BI using a fictitious dataset on personal finances. It tracks and analyzes monthly expenses, incomes, profits, and balance for the years 2024 and 2025, providing insights into financial performance and trends over time. 
The interactive dashboard is available here:
